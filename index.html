Abstract

Teaching robots to use previously unseen tools requires both high-level semantic reasoning about how a tool should be used and low-level physical reasoning about how interactions will unfold. Recent vision-language planning methods provide strong semantic priors, while visual world models offer a way to evaluate candidate actions through imagined rollouts; however, existing approaches rely on improving the planner or policy while assuming the world model to be correct. Our key idea is to learn an action-conditioned, uncertainty-aware world model tailored to the task of interest by bootstrapping from a prior model and VLM-generated plans. At train time, we select a small number of VLM plans for execution based on the expected reward and the uncertainty estimate from the world model. The observed outcomes of these executions are used to learn a task-focused world model and its uncertainty estimate. At test time, this uncertainty-aware world model is used to select the best VLM-proposed plan for execution. We show that this self-supervised method of learning a task-focused world model enables success on unseen tool-use manipulation tasks, improves over ablations without uncertainty awareness, and outperforms end-to-end policy learning baselines.
